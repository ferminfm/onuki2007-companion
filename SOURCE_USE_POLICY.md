# Source-Use Policy

This project is an original derivation companion. It cites equation and page
anchors for navigation, reconstructs calculations independently, and keeps the
original publications necessary for source context. It does not distribute
source PDFs, scans, books, or long copied passages.

When a primary-source branch is ambiguous, the public text labels the ambiguity
instead of silently repairing it. Bounded statements about the printed Appendix
B B3 term do not assert an official erratum, author intent, unpublished
implementation behavior, or numerical impact.
