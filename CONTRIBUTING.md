# Contributing

Make scientific and editorial changes in the canonical `ferminfm/latex`
subtree. Do not edit an exported standalone mirror.

Before proposing a change, run the smallest relevant check, then `make
verify-open` when practical. New mechanically checkable derivations need a
visible hand derivation, a stable check identifier, an executable map, a
negative control when a factor or sign is fragile, and an explicit scope limit.

Do not add source PDFs, scans, generated PDFs, caches, credentials, local paths,
or numerical-reproduction outputs. Do not upgrade a bounded source issue to an
erratum, author-intent conclusion, model equivalence, or simulation result
without new primary evidence and review.
