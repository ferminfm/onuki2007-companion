# Formal Scope

Lean modules in this project formalize finite algebraic or implication kernels
with explicit hypotheses. They do not prove the second law, constitutive
physics, global energy closure, PDE well-posedness, numerical reproduction, or
full equivalence between continuum models. The source text and companion hand
derivations remain the primary scientific explanation.

The exact declarations, finite hand proofs, and command route are in
`docs/formal/theorem-index.md` and `scripts/verify_formal_project.sh`.
