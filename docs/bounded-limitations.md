# Bounded Limitations

The companion retains source-dependent or deferred issues rather than silently
closing them: the source Eq. (2.5) profile branch, Eq. (3.9) interface condition,
printed Appendix-B B3 versus the dimensional-source branch, unpublished
simulation-code behavior, local versus global flux and wall transfer, boundary
and admissible-variation maps, direct Korteweg 1901 source limits, and deferred
Dunn--Serrin equation-level audit. It does not claim numerical reproduction,
author intent, an official erratum, or full model equivalence.
